# Chapter 3.2 因子逻辑与结果笔记

本笔记解释 `code/chapter3/factors` 目录下两个日频因子脚本：

- `factor31.py`：严格沿用 Chapter 2 的 23 号因子作为龙头识别信号，再做空同板块、高相关的跟随品种。
- `factor32.py`：沿用 23 号因子的信号框架，但把参数做成可配置，并使用更宽松的默认入场条件和更低的关系度阈值，扩大样本数量。

两个脚本的核心思想一致：信号不直接交易触发信号的品种，而是先把它当作板块龙头，再把交易落到同板块的跟随品种上。

## 1. 总体流程

```text
读取 Chapter 2 生成的日频数据
    ↓
为每个品种补充 symbol、group、daily_return
    ↓
按 23 号因子式规则计算 open_short_signal 和 factor_value
    ↓
同一天、同板块内，只保留 factor_value 最高的品种作为龙头
    ↓
寻找同板块、非龙头、过去 20 日收益率关系度足够高的跟随品种
    ↓
信号日收盘确认，下一交易日开盘做空跟随品种
    ↓
沿用空头平仓规则，平仓信号收盘确认，下一交易日开盘平空
    ↓
输出龙头信号、跟随信号、交易明细、日收益和绩效指标
```

输入默认来自：

```text
results/chapter2/tables/daily/*_daily.csv
```

输出默认写入：

```text
results/chapter3/factor31/
results/chapter3/factor32/
```

## 2. 龙头识别逻辑

两个脚本都会先对每个品种调用 Chapter 2 的 `add_entry_signals`，生成：

- `open_short_signal`：是否满足开空条件。
- `factor_value`：信号强度分数，只用于同板块排序，不直接决定收益计算。

开空条件由均线偏离、持仓斜率、价格斜率、投机度斜率共同构成。以 23 号因子为例：

```text
open_short_signal =
    ma_bias_spread_signal
    and ma_long_bias_spread_signal
    and oi_slope_signal
    and close_slope_signal
    and speculation_slope_signal
```

直观解释是：价格处于偏高状态，同时价格、持仓和投机度开始回落，因此产生做空候选信号。

同一天、同板块内如果有多个品种触发 `open_short_signal == 1`，程序按：

```text
date, group, factor_value desc, symbol asc
```

排序，并对每个 `date + group` 只保留第一行。也就是说，每个板块每天最多只有一个龙头。

输出到：

```text
leader_signals.csv
```

主要字段含义：

| 字段 | 含义 |
| --- | --- |
| `信号日` | 龙头触发开空信号的日期。 |
| `板块` | 由 `chapter3/common/config.py` 的 `GROUP` 映射得到。 |
| `龙头品种` | 当天同板块 `factor_value` 最高的触发信号品种。 |
| `龙头得分` | `factor_value`，用于选龙头。 |
| `龙头当日收益率` | 龙头信号日的日收益率。 |

## 3. 跟随品种识别逻辑

找到龙头后，程序遍历所有品种，筛选跟随品种：

```text
跟随品种条件 =
    不是龙头自己
    + 和龙头属于同一板块
    + 信号日当天有日频行情
    + 龙头和候选品种过去 20 日收益率相关性达到阈值
```

关系度的计算口径是：

```text
corr(
    leader 过去 20 个交易日 daily_return,
    follower 过去 20 个交易日 daily_return
)
```

注意这里用的是信号日前的 20 个交易日，不包含信号日当天，避免使用未来信息。两边按日期合并后，如果不足 20 个有效样本，就不参与筛选。

输出到：

```text
follower_signals.csv
```

主要字段含义：

| 字段 | 含义 |
| --- | --- |
| `信号日` | 龙头信号日期，也是跟随信号确认日期。 |
| `板块` | 龙头和跟随品种所属板块。 |
| `龙头品种` | 触发信号并被选为板块龙头的品种。 |
| `跟随品种` | 实际准备做空的品种。 |
| `20日相关系数` / `20日关系度` | 过去 20 日收益率相关系数。 |
| `龙头当日收益率` | 信号日龙头日收益率。 |
| `跟随当日收益率` | 信号日跟随品种日收益率。 |

## 4. 交易执行与平仓逻辑

交易只发生在跟随品种上，不交易龙头品种本身。

开仓规则：

```text
信号日 t 收盘确认跟随信号
下一交易日 t+1 开盘价做空跟随品种
```

平仓规则：

```text
持仓期间每日收盘检查空头退出条件
如果触发退出，下一交易日开盘价平空
```

空头收益率计算为：

```text
收益率 = 开空价 / 平空价 - 1
```

也就是价格下跌赚钱，价格上涨亏钱。

退出条件来自 Chapter 2 的 `check_short_exit`：

- `price_above_entry`：收盘价重新高于开仓线。
- `trailing_rebound`：价格从入场后的最低点反弹超过波动率阈值。
- `price_above_entry_and_trailing_rebound`：两个条件同时触发。

每个跟随品种同一时间只允许一笔空头持仓。持仓期间出现的新跟随信号不会叠加开仓；脚本也不会在数据结束时强制平掉仍未触发退出的持仓。

## 5. factor31 的具体逻辑和结果

`factor31.py` 的定位是严格复用 23 号因子：

```text
ENTRY_CONFIG = chapter2/factors/factor_23.py 的 ENTRY_CONFIG
EXIT_CONFIG  = chapter2/factors/factor_23.py 的 EXIT_CONFIG
USE_SPECULATION = True
LOOKBACK_DAYS = 20
CORRELATION_THRESHOLD = 0.5
```

23 号因子的关键默认参数：

| 参数 | 值 | 含义 |
| --- | ---: | --- |
| `ma_short` | 5 | 短均线窗口。 |
| `ma_long` | 20 | 中期均线窗口。 |
| `ma_trend` | 60 | 趋势均线窗口。 |
| `ma_bias_threshold` | 0.04 | 短中均线偏离阈值。 |
| `ma_long_bias_threshold` | 0.10 | 相对长期均线偏离阈值。 |
| `oi_slope_window` | 5 | 持仓斜率窗口。 |
| `close_slope_window` | 7 | 收盘价斜率窗口。 |
| `speculation_slope_window` | 5 | 投机度斜率窗口。 |
| `speculation_slope_threshold` | -0.01 | 投机度回落阈值。 |
| `volatility_window` | 10 | 平仓用波动率窗口。 |
| `trailing_multiplier` | 4.0 | 回撤止盈的波动率倍数。 |

跟随筛选条件是：

```text
20日相关系数 >= 0.5
```

现有输出结果：

| 指标 | 数值 |
| --- | ---: |
| 龙头信号数 | 100 |
| 跟随信号数 | 165 |
| 完成交易数 | 100 |
| 胜率 | 23.00% |
| 累计收益率 | 136.39% |
| 最大回撤 | 21.21% |

这里的累计收益率来自 `daily_returns.csv` 的单利口径：同一平仓日多笔交易先取平均收益，再按日期累加，不做复利再投资。

从样例看，factor31 的信号比较少，主要是因为它完全继承了 23 号因子较严格的入场阈值，并且要求跟随品种和龙头的 20 日相关系数至少达到 0.5。

## 6. factor32 的具体逻辑和结果

`factor32.py` 是 factor31 的扩展版。它仍使用同一套“先选龙头、再做空跟随品种”的流程，但有三个重要差异：

1. 入场参数在脚本内部定义，并且可以通过命令行覆盖。
2. 默认入场条件比 23 号因子宽松。
3. 关系度阈值默认降低到 `> 0.35`，因此生成更多跟随交易。

默认参数：

| 参数 | 值 | 含义 |
| --- | ---: | --- |
| `ma_short` | 5 | 短均线窗口。 |
| `ma_long` | 20 | 中期均线窗口。 |
| `ma_trend` | 60 | 趋势均线窗口。 |
| `ma_bias_threshold` | 0.00 | 短中均线偏离阈值，比 23 号更宽。 |
| `ma_long_bias_threshold` | 0.02 | 相对长期均线偏离阈值，比 23 号更宽。 |
| `oi_slope_window` | 5 | 持仓斜率窗口。 |
| `close_slope_window` | 7 | 收盘价斜率窗口。 |
| `speculation_slope_window` | 3 | 投机度斜率窗口。 |
| `speculation_slope_threshold` | -0.005 | 投机度回落阈值，比 23 号更宽。 |
| `volatility_window` | 7 | 平仓用波动率窗口。 |
| `RELATION_THRESHOLD` | 0.35 | 跟随关系度阈值。 |
| `trailing_multiplier` | 2.5 | 回撤止盈的波动率倍数，比 factor31 更紧。 |
| `entry_loss_volatility_multiplier` | 0.0 | 收盘价高于开仓价即触发入场线止损。 |

跟随筛选条件是：

```text
20日关系度 > 0.35
```

这里的“关系度”实际就是过去 20 日收益率相关系数，只是字段名从 `20日相关系数` 改成了 `20日关系度`。

现有输出结果：

| 指标 | 数值 |
| --- | ---: |
| 龙头信号数 | 1,897 |
| 跟随信号数 | 3,524 |
| 完成交易数 | 1,945 |
| 胜率 | 22.78% |
| 累计收益率 | 609.19% |
| 最大回撤 | 19.07% |

factor32 的交易数量显著高于 factor31，主要来自两个变化：入场阈值放松、关系度阈值从 `>= 0.5` 降为 `> 0.35`。虽然胜率仍然只有约 23%，但单利累计收益更高，说明盈利交易的平均幅度大于亏损交易，且更紧的移动止盈/止损规则控制了回撤。

## 7. 输出文件说明

两个因子都会输出以下文件：

| 文件 | 含义 |
| --- | --- |
| `leader_signals.csv` | 每日每板块选出的龙头信号。 |
| `follower_signals.csv` | 满足关系度阈值的跟随品种信号。 |
| `trades.csv` | 实际完成的空头交易明细。 |
| `daily_returns.csv` | 按平仓日汇总后的日收益、累计净值和回撤。 |
| `metrics.csv` | 交易次数、胜率、累计收益率、最大回撤。 |

factor32 额外输出：

| 文件 | 含义 |
| --- | --- |
| `parameters.csv` | 本次运行使用的入场参数、退出参数和关系度阈值。 |

`trades.csv` 的关键字段：

| 字段 | 含义 |
| --- | --- |
| `信号日` | 龙头和跟随关系确认日期。 |
| `开空日` | 实际开空日期，通常是信号日的下一交易日。 |
| `平空日` | 实际平空日期，通常是退出信号后的下一交易日。 |
| `龙头品种` | 只用于识别，不是实际交易对象。 |
| `跟随品种` | 实际做空的品种。 |
| `开空价` | 开空日开盘价。 |
| `平空价` | 平空日开盘价。 |
| `收益率` | `开空价 / 平空价 - 1`。 |
| `平仓原因` | 触发的退出规则。 |

## 8. 结果解读要点

factor31 更像一个严格版验证：它检验“23 号因子触发的龙头，是否能传导到同板块强相关跟随品种”。样本少，但规则更接近原始 23 号因子。

factor32 更像一个放量版策略：它保留龙头-跟随框架，但放宽开仓条件和关系度门槛，换来更多信号和更高累计收益。结果中胜率不高，但累计收益和最大回撤组合更好，说明这个策略更依赖少数较大的趋势段盈利，而不是高频率的小胜率。

阅读结果时需要注意三点：

1. 绩效是单利、按平仓日平均收益汇总，不是组合资金曲线。
2. 未考虑手续费、滑点、保证金占用和不同品种合约乘数。
3. 多个品种同日交易时直接平均，尚未做风险预算或板块暴露控制。
